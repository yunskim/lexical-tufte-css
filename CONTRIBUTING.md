# Contributions and reuse

The repository owner's existing choice, **GPL-3.0-only**, is retained for project code. No linking exception, dual license, or permission to relicense third-party works is added. Package SPDX metadata and the root LICENSE use this same policy.

Contributors retain their copyright. Submit original contributions under GPL-3.0-only and retain third-party notices. No copyright assignment or CLA is required by this project. New external contributions should include a `Signed-off-by: Name <email>` line certifying the [Developer Certificate of Origin 1.1](https://developercertificate.org/). Existing commits are not retroactively signed or altered.

User-authored posts, photographs and documents remain their authors' material; the project does not impose its source license on them merely for using the editor. Generated output that incorporates covered program code or redistributed styles/fonts must retain the applicable licenses. See the [GNU FAQ on program output](https://www.gnu.org/licenses/gpl-faq.html#GPLOutput) and the actual included notices. An editor bundle and the author's article are different distributed material; do not promise universal compatibility with proprietary applications.

Source Han font derivatives remain OFL-1.1. Modified proof subsets use distinct primary font names; original provenance and Adobe notices are retained. Tufte CSS/ET Book/Lexical retain their own licenses. See THIRD_PARTY_NOTICES.md and licenses/.

Before submitting: run the local `pnpm check` and relevant browser tests. CI is intentionally omitted. Record actual errors and prevention actions in docs/ERROR_LOG.md and docs/ERROR_PREVENTION.md. Packaging checks create local tarballs only; they do not publish packages.
