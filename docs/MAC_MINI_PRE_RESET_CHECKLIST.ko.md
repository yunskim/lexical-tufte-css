# 맥미니 초기화 전 체크리스트

맥미니를 지우기 전에 다른 컴퓨터에서 이 문서를 열어 두고, 해당하는 항목을 확인한다. 백업은 초기화할 맥미니 외부에 저장하고 실제로 복원할 수 있는지 확인한다.

## 저장소와 작업 중인 파일

- [ ] `lexical-tufte-css` 및 맥미니에서 작업한 다른 저장소를 각각 확인한다. `git status --short --branch`로 수정 및 미추적 파일을 보고, `git branch -vv`로 로컬 브랜치와 추적 상태를 확인한다.
- [ ] 필요한 커밋과 브랜치는 해당 GitHub 저장소에 푸시하고 다른 컴퓨터에서 보이는지 확인한다. 아직 커밋할 준비가 되지 않은 변경, 미추적·무시 파일, `git stash list`에 있는 작업은 외부 백업에 보관한다.
- [ ] 로컬 문서, 테스트 자료, 작업 중인 내보내기 파일, 개발용 DB와 업로드 파일 등 Git으로 복구할 수 없는 자료를 백업한다. 실행 중인 DB는 해당 DB의 백업 명령으로 내보낸다.

## 개발 환경과 접속 정보

- [ ] 다시 설치할 도구와 사용 버전을 기록한다. Homebrew 목록, Node와 패키지 매니저, Python, Rust 툴체인, 셸 설정, 프로젝트별 실행 명령을 필요한 범위에서 남긴다.
- [ ] `.env`와 로컬 설정, SSH·서명 키의 복구 또는 재발급 방법을 확인한다. 비밀 값과 개인 키는 암호화된 백업이나 비밀번호 관리자에 보관한다.
- [ ] 다른 기기에서 GitHub와 Tailscale에 로그인할 수 있는지 확인한다. 다중 인증과 복구 수단도 맥미니 밖에서 접근할 수 있어야 한다.
- [ ] 기존 LAN 주소나 DHCP 예약, Tailscale 장치 이름, SSH 허용 계정 등 다시 설정할 항목을 개인 메모에 기록한다. 초기 설정에 쓸 모니터·키보드와 네트워크 연결을 준비한다.

## GitHub Actions 러너

- [ ] 해당하는 경우 GitHub의 러너 등록 범위(저장소 또는 조직), 러너 이름·그룹·라벨, 워크플로의 `runs-on` 값을 기록한다.
- [ ] 실행 중인 작업이 끝났는지 확인하고 대기 작업이 있으면 새 러너 등록 후 처리할 작업을 기록한다.
- [ ] 러너 계정에만 설치했던 도구와 서비스의 시작 방식, 별도 환경 변수 또는 키체인 의존성을 기록한다. GitHub에서 새 러너를 등록할 권한이 있는지 확인한다.

## 지우기 직전

- [ ] 외장 디스크 또는 다른 컴퓨터에서 필요한 파일과 DB 백업을 직접 열어 보고, 대표 파일 하나를 복원해 본다.
- [ ] 다른 컴퓨터에서 GitHub의 필요한 브랜치를 열고 주요 작업이 보이는지 확인한다.
- [ ] 외장 백업을 분리한 뒤 맥미니에서 **시스템 설정 → 일반 → 전송 또는 재설정 → 모든 콘텐츠 및 설정 지우기**를 진행한다. [Apple 초기화 안내](https://support.apple.com/ko-kr/102664)
